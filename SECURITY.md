# Security policy

Do not use a public issue to report a vulnerability, exposed credential, or
personal-data incident.

Send the report to `contact@ferno.ag`. Include the affected component, the
impact, and the minimum steps that reproduce the problem. Remove credentials,
private keys, access tokens, customer records, and other personal data from the
report. We will request a secure transfer method if more evidence is required.

Stargazer is a proof of concept. It is not a production alerting service. Do not
use it as the only control for assets, keys, contracts, or incident response.

Security fixes apply to the current default branch. Older snapshots are not
supported.
