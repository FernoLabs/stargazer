# Ferno Pulsar web

SvelteKit website for Ferno Pulsar.

The public product page is served at `/`. The grant working page is served at
`/scf/application` with `noindex`, `nofollow`, and `noarchive` headers.

## Developing

```bash
npm ci
npm run dev
```

## Verification

```bash
npm run check
npm run build
```
